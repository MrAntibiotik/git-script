# Mono Donate — OBS-плагін для донатів

Донати через **банку Monobank** з алертом прямо у сцені OBS.
Алерт є частиною відео, тому його бачать глядачі **на всіх платформах**
(Twitch, YouTube, TikTok, Kick…), зокрема при мультистрімі через Aitum Multistream.

## Як це працює

1. Глядач донатить на вашу банку (посилання `send.monobank.ua/jar/...`).
2. Плагін раз на хвилину перевіряє виписку банки через API Monobank.
3. Для нового донату показується текст «Донат від Олена: 150 грн!» плюс коментар,
   програється звук, а за бажанням оновлюється прогрес збору.

## Встановлення

1. OBS → **Інструменти → Скрипти → Налаштування Python**: вкажіть шлях до Python 3.
2. На вкладці **Скрипти** натисніть **+** і виберіть `mono_donate.py`.
3. Отримайте особистий токен на <https://api.monobank.ua/> і вставте його в поле «Токен Monobank».
4. Натисніть **Завантажити банки** і виберіть банку.
5. У сцені створіть:
   - джерело **Текст (GDI+ / FreeType2)** для алерту;
   - за бажанням **Медіа-джерело** зі звуком (вимкніть «Повторювати» і «Перезапускати при активації»);
   - за бажанням ще один **Текст** для прогресу збору.
6. Виберіть ці джерела в налаштуваннях скрипта й натисніть **Тестовий донат**.

## Шаблони

- Алерт: `{name}`, `{amount}`, `{currency}`, `{comment}`
- Збір: `{balance}`, `{goal}`, `{currency}`, `{title}`

## Обмеження

- Monobank дозволяє 1 запит виписки на хвилину, тому алерт може з'явитися із затримкою до ~60 с.
- Токен дає доступ лише на читання, але не публікуйте його й не показуйте на стрімі.
